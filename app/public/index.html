Connect Claude Code

Set environment variables:

SET ANTHROPIC_BASE_URL=http://127.0.0.1:4096
SET ANTHROPIC_API_KEY=not-needed
claude

Or PowerShell:

$env:ANTHROPIC_BASE_URL="http://127.0.0.1:4096"
$env:ANTHROPIC_API_KEY="not-needed"
claude
Important: Claude Code gọi model như claude-sonnet-4-6, claude-opus-4-8, claude-haiku-4-5... Các model này không có sẵn trên OpenCode Free. Bạn cần map model ở Mappings tab.

Quick Start (Windows)

        
Run Claude Code through this proxy:

        
proxy-claude.cmd

        
Or manually set env vars then run claude:

        
$env:ANTHROPIC_BASE_URL="http://127.0.0.1:4096"
$env:ANTHROPIC_API_KEY="not-needed"
claude
